获取 Cookie 详细指南

照着下面 6 步做，每一步都配了示意图

1

打开微博并登录

用 Chrome 浏览器打开 https://m.weibo.cn

输入账号密码登录，或用微博 App 扫码登录。

确保登录成功，能看到微博首页内容后再进行下一步。
2

按 F12 打开开发者工具

按键盘上的 F12 键。

如果按了没反应（部分笔记本），请同时按 Fn + F12。

屏幕上会出现一个很大的面板（在右侧或底部），这就是开发者工具。

🖥️ 按 F12 后，屏幕右侧或下方会出现这个面板
3

找到并点击 Network 标签

在开发者工具面板的最顶部，有一行标签：

Elements Console Sources Network Performance >>

点击 Network（网络）标签。

如果看不到 Network，点顶部最右边的 >> 展开更多标签。
4

刷新页面

按 F5 或者 Ctrl + R 刷新页面。

刷新后，Network 标签里会出现一列请求列表（文件名列表）:

Network
getIndex?type=uid...
getIndex?type=uid...
statuses/show...
profile/info...
sax?
Request Headers （请求头）
User-Agent:
Accept:
Cookie: WEIBOCN_FROM=111000...

点击左侧 第一个请求（通常是 getIndex 开头的）。

5

复制 Cookie

点击第一个请求后，右侧会显示详情。找到 Request Headers 区域。

往下翻，找到以 Cookie: 开头的那一行。

你会看到类似这样的内容（很长，这只是示例）：
Cookie: WEIBOCN_FROM=1110006030; SUB=_2A25HTz9VDe...; SCF=AuFGshw6x...; SUBP=0033WrSXqPxf...; SSOLoginState=1783320325; ...

选中 Cookie: 后面的全部内容（从 WEIBOCN_FROM 开始到最后），右键复制。

⚠️ 注意：只复制 Cookie: 后面的内容，不要复制 "Cookie: " 这几个字。

6

粘贴到配置文件

打开文件夹中的 data\config.yaml 文件（用记事本打开）。

找到这行：

cookie: ""

改成（把刚才复制的内容粘贴到引号中间）：

cookie: "WEIBOCN_FROM=1110006030; SUB=_2A25HTz9VDe...（你复制的内容）"

保存文件（按 Ctrl + S）。

✅ 大功告成！现在双击 start.bat 启动服务吧！
✓

验证是否成功

双击 start.bat 启动后，浏览器打开 http://127.0.0.1:5000

如果看到仪表盘页面，并且状态显示"已配置"，就说明 Cookie 填对了！

点击「启动监控」→ 开始自动抓取微博。

❓ 常见问题

Q: 我找不到 Network 标签怎么办？

A: 按 F12 后，如果顶部没有 Network，点最右边的 >> 展开全部标签。

Q: 我点了第一个请求，但没有看到 Cookie？

A: 点其他请求试试。或者点刷新按钮右侧的小箭头 → 点第一个请求

Q: Cookie 填写后保存，但页面还是说未配置？

A: 先关掉 start.bat 窗口，重新双击 start.bat 启动一次。

Q: Cookie 里有中文或特殊符号，需要处理吗？

A: 不需要。直接复制粘贴即可。

Q: 之前能用的，突然抓不到微博了？

A: Cookie 过期了。从第 1 步重新来一遍，获取新的 Cookie 填进去。
