Weibo Watcher v1.2 - 微博监控器
===================================

实时监控指定微博用户的发帖，发出即抓取，本地存档，不怕删帖。


【使用步骤 - 三步搞定】
------------------------


第一步：安装（只需一次）
~~~~~~~~~~~~~~~~~~~~~~~~~

  找到本文件夹，双击 install.bat

  程序会自动：
  - 检测电脑上有没有 Python（如没有会提示你去官网下载）
  - 创建虚拟环境
  - 安装所需依赖包

  整个过程约 1-3 分钟，请耐心等待。
  安装完成后桌面会生成"微博监控器"快捷方式，以后直接用。


第二步：获取并填写 Cookie（只需做一次，但最关键）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

   Cookie 是你的微博账号的身份凭证，用来让程序登录微博抓取内容。
   没有 Cookie，程序无法工作。

   ---------- 下面是详细步骤，照着做，不会错 ----------

   【第 1 步】用 Chrome 浏览器打开 https://m.weibo.cn

   【第 2 步】登录你的微博账号（扫码登录或账号密码登录）

   【第 3 步】按键盘上的 F12 键
             （笔记本可能需要按 Fn + F12）

   【第 4 步】屏幕上会出现一个很大的开发工具面板
             在最顶部有一行标签，找到"Network"（网络）并点击它
             如果看不到，点最右边的 >> 展开更多标签

   【第 5 步】按 F5 键刷新页面
             左边会出现一列请求列表，点第一个请求

   【第 6 步】在右侧面板中，找到"Request Headers"（请求头）区域
             往下翻，找到以 Cookie: 开头的一行
             这一行很长，后面跟着一串像这样的内容：
             
             WEIBOCN_FROM=1110006030; SUB=_2A25...; SCF=...;
             
             选中 Cookie: 后面的所有内容（不包括"Cookie: "这几个字）
             右键 → 复制

   【第 7 步】打开本文件夹内的 data/config.yaml 文件
             （用记事本打开即可：右键 → 打开方式 → 记事本）

   【第 8 步】找到这一行：
             cookie: ""
  
             改成：
             cookie: "你刚才复制的那一串内容"
  
             注意：前后引号不能丢，内容不要换行。
             修改后保存文件（Ctrl + S）


第三步：启动服务
~~~~~~~~~~~~~~~~

  方式一：双击本文件夹内的 start.bat
  方式二：双击桌面上的"微博监控器"快捷方式

  浏览器自动打开 http://127.0.0.1:5000
  看到仪表盘界面即表示启动成功。

  关闭启动窗口 = 停止服务。


【在浏览器里能做什么】
----------------------

  仪表盘    查看监控状态：已捕获多少条、运行/暂停/停止
           点击按钮控制监控的启动、暂停和停止

  设置      修改 UID（监控谁）和 Cookie（身份凭证）
           Cookie 过期了就来这里更新

  微博存档  按时间倒序浏览所有已保存的微博
           点击任意一条可以查看完整内容

  运行日志  查看程序运行记录，出问题时排查原因


【文件说明】
------------

  install.bat          一键安装程序（只需运行一次）
  start.bat            启动服务（每次用这个）
  data/config.yaml     配置文件（UID + Cookie 都在这）
  data/posts_index.json 帖子索引（JSON，用于快速检索和列表展示）
  data/posts/           存档目录
    第三步：启动
      双击 start.bat
      → 服务在后台启动，窗口自动关闭
      → 浏览器自动打开 http://127.0.0.1:5000
      → 看到仪表盘界面即表示启动成功

    停止服务
      双击 stop.bat
      → 一键停止后台监控服务
      → 关掉浏览器页面即可

    【常见问题】
    ------------

    Q: 双击 start.bat 后浏览器没自动打开？
    A: 手动打开浏览器，输入 http://127.0.0.1:5000 回车

    Q: 双击 start.bat 提示端口被占用？
    A: 先双击 stop.bat 停掉旧进程，再启动即可

    Q: 页面显示"未配置"？
A: 先去"设置"页面，填入 Cookie，点击"保存并重启监控"

Q: 运行了一段时间后突然抓不到微博了？
A: 通常是 Cookie 过期了。重复"第二步"重新获取 Cookie，
   到浏览器设置页面粘贴保存即可。无需重新安装。

Q: Cookie 多久过期？
A: 一般几天到几周不等，没有固定时间。发现抓不到时
   重新获取一次即可。

Q: 怎么开机自动启动？
A: 把 start.bat 的快捷方式放到 Windows 启动文件夹：
   按 Win + R 键 → 输入 shell:startup → 回车
   → 把 start.bat 拖进去

Q: 电脑重启后还需要重新操作吗？
A: 只需双击 start.bat 即可，之前已保存的微博都在。
   不需要重新安装，也不需要重新获取 Cookie（除非过期）。

Q: 我想换个监控对象怎么办？
A: 在浏览器设置页面修改 UID 即可。


【技术支持】
------------

这些日志记录了程序的运行情况，可以快速定位问题。
